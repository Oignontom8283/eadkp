Le format de couleur RGB 565 ​

Le RGB 565 décrit une couleur sur 16 bits (2 octets). C'est le format des pixels de l'écran de la NumWorks, et donc celui des images EIF.

RGB 888 : le format habituel ​

Quand on écrit une couleur en RGB sans autre précision, c'est du RGB 888 : trois nombres de 0 à 255, un pour le rouge, un pour le vert, un pour le bleu.

css
rgb(255, 0, 0)     /* rouge */
rgb(66, 138, 245)  /* bleu clair */
1
2

Chaque nombre tient sur 8 bits, d'où le nom « 888 ». Un pixel prend donc 3 octets, et on dispose de 16 777 216 couleurs.

RGB 565 : moins de bits par couleur ​

Le RGB 565 garde les mêmes trois couleurs, mais avec moins de bits :

CouleurBitsValeurs possibles
Rouge50 à 31
Vert60 à 63
Bleu50 à 31

Cela fait 16 bits, soit 2 octets par pixel, et 65 536 couleurs possibles.

Le vert a un bit de plus parce que l'œil distingue mieux les nuances de vert que celles du rouge ou du bleu. Avec 16 bits, on les donne à la couleur qui compte le plus.

Pourquoi ce choix ​

L'écran fait 320 × 240 = 76 800 pixels.

FormatOctets par pixelTaille d'une image plein écran
RGB 8883230 400 octets (225 Kio)
RGB 5652153 600 octets (150 Kio)

Une image plein écran pèse donc un tiers de moins. Sur une calculatrice dont la RAM fait environ 256 Kio, la différence compte. De plus, 2 octets tiennent exactement dans un entier u16, ce qui évite de découper des octets en morceaux.

Comment un pixel est rangé ​

Les 16 bits sont, de gauche à droite : 5 bits de rouge, 6 de vert, 5 de bleu.

rouge  vert    bleu
01000  100010  11110
  8      34     30
1
2
3

Ce pixel vaut 0b0100010001011110, soit 17 502 en décimal (0x445E en hexadécimal).

Convertir une couleur ​

De RGB 888 vers RGB 565 ​

On garde seulement les bits de gauche de chaque couleur, ceux qui comptent le plus, et on jette les autres : 3 bits pour le rouge et le bleu, 2 bits pour le vert. C'est ce que fait la conversion des images au moment de la compilation (builder.rs).

rust
fn rgb888_vers_rgb565(r: u8, g: u8, b: u8) -> u16 {
    let r5 = (r >> 3) as u16;
    let g6 = (g >> 2) as u16;
    let b5 = (b >> 3) as u16;

    (r5 << 11) | (g6 << 5) | b5
}

// rgb888_vers_rgb565(66, 138, 245) == 17 502

De RGB 565 vers RGB 888 ​

On étend chaque valeur à 8 bits. Pour que le maximum reste le maximum (31 doit redonner 255), on recopie les bits de gauche dans les places libres à droite.

rust
fn rgb565_vers_rgb888(couleur: u16) -> (u8, u8, u8) {
    let r5 = (couleur >> 11) & 0b11111;
    let g6 = (couleur >> 5) & 0b111111;
    let b5 = couleur & 0b11111;

    let r8 = (r5 << 3) | (r5 >> 2);
    let g8 = (g6 << 2) | (g6 >> 4);
    let b8 = (b5 << 3) | (b5 >> 2);

    (r8 as u8, g8 as u8, b8 as u8)
}

// rgb565_vers_rgb888(17 502) == (66, 138, 247)
